1. Singleton Pattern
Creational

Intent: Ensure a class has ONLY ONE instance and provide a global access point.

Exam Scenario: Central logging service or database connection pool that must be shared app-wide.
public class DBConnection { private static DBConnection _instance; private DBConnection() {} // Private Constructor! public static synchronized DBConnection getInstance() { if (_instance == null) _instance = new DBConnection(); return _instance; } }
2. Factory Method
Creational

Intent: Define interface for creating an object, but let subclasses decide which class to instantiate.

Exam Scenario: Graphics editor supporting Windows, macOS, and Linux UI components.
interface Button { void render(); } class WinButton implements Button { public void render() { ... } } abstract class Dialog { abstract Button createButton(); // Factory Method }
3. Adapter Pattern
Structural

Intent: Convert interface of a class into another interface clients expect (Wrapper for legacy code).

Exam Scenario: New HR system needs to talk to old legacy payroll system without modifying old code.
public class PayrollAdapter implements INewHR { private LegacyPayroll _legacy; // Reference to legacy public PayrollAdapter(LegacyPayroll legacy) { this._legacy = legacy; } public void processPay() { _legacy.oldPayMethod(); } // Delegate }
4. Decorator Pattern
Structural

Intent: Attach additional responsibilities to an object dynamically at runtime without altering class.

Exam Scenario: Adding scrollbars to text box, borders to buttons, or coffee toppings.
abstract class WidgetDecorator implements Widget { protected Widget _wrappedWidget; public WidgetDecorator(Widget w) { this._wrappedWidget = w; } public void draw() { _wrappedWidget.draw(); } }
5. Observer Pattern
Behavioral

Intent: Publish/Subscribe model. When one object changes state, all subscribers are updated.

Exam Scenario: University sends Email, SMS, Slack notifications when course is cancelled.
interface Observer { void update(String msg); } class CourseSubject { private List _observers = new ArrayList<>(); public void notify(String msg) { for (Observer o : _observers) o.update(msg); } }
6. Strategy Pattern
Behavioral

Intent: Encapsulate family of interchangeable algorithms and select best fit at runtime.

Exam Scenario: Shipping calculator with if (country == "USA") ... else if ("Canada") ladder.
interface IShippingStrategy { double calculate(Order o); } class USAShipping implements IShippingStrategy { ... } class OrderService { private IShippingStrategy _strategy; public OrderService(IShippingStrategy s) { this._strategy = s; } }
